# デザイン刷新 決定ログ（2026-10-25）

4 本の批評（`critique/01_foundation.md` 基盤、`02_browse.md` ホーム・問題・履歴、`03_session.md` 事前確認・面接、`04_review.md` レビュー）を統合し、食い違いをここで決める。実装はこのファイル → `DESIGN_SYSTEM.md`（基盤仕様）→ 各 critique の順に従う。

## 方針

- デジタル庁デザインシステム（DADS, MIT）の **primitive カラー・タイポ命名・フォーカスリング・状態表現の文法** を採用し、**密度・ダークモード・可視化・セッション中の静けさ** は LCI 側で拡張・逸脱する（01 §2）。
- DADS の Tailwind テーマ `v4.css` は `@import` しない。primitive を `--dads-*` として取り込み、LCI の semantic トークンだけを `@theme inline` に出す（01 §3.2）。
- フォントはシステムフォント（Hiragino 系 + システム等幅）。Web フォントは同梱しない（01 §6）。

## 実装の分担

1. 基盤（トークン・`components/ui/*`・グローバルヘッダ・Monaco テーマ）を先に入れる。
2. その上で 3 画面群（閲覧 / セッション / レビュー）を並列で刷新する。
3. 刷新前後のスクリーンショット比較、テスト・ビルド・E2E で検証する。
